# Laboratorio de historia espacial

Página interactiva para la Sesión 9 del curso Historia Digital (UNAL, 2026-2S). Recorre los fundamentos de la historia espacial: los cinco rasgos de Richard White, la tríada de Henri Lefebvre, el espacio absoluto frente al relacional, la visualización como método, el gráfico de Minard por capas y el trabajo con SIG.

Es un solo archivo (`index.html`), sin dependencias que instalar. Las fuentes se cargan desde Google Fonts.

## Publicar con GitHub Pages

1. Cree un repositorio nuevo en GitHub (por ejemplo, `historia-espacial`) y márquelo como público.
2. Pulse **Add file → Upload files**, arrastre `index.html` y este `README.md`, y pulse **Commit changes**.
3. Vaya a **Settings → Pages**. En **Branch** elija `main` y la carpeta `/ (root)`. Pulse **Save**.
4. En uno o dos minutos la página queda en `https://<su-usuario>.github.io/historia-espacial/`.

## Nota sobre los datos

Los tiempos de viaje en Bogotá, la tabla de tarifas y los valores de los predios del módulo de capas son ilustrativos y están construidos para el ejercicio. El gráfico de Minard usa los datos del original de 1869.
